# 修复 Agent

状态：P0-05a已实现`contracts.py`及角色单测；运行逻辑/提示词仍待P0-05b。

| 项目 | 约束 |
|---|---|
| 输入 | 已验证失败、诊断假设、允许修改的文件与预算。 |
| 输出 | 文件白名单内的局部候选补丁和修改依据；不能输出“已修复”代替回归结果。 |
| 权限 | P0-05 只能建议补丁；P0-06 的隔离副本/只读验收/预算检查通过后才能应用，不可直接修改原始工作区。 |
| 验收 | 越界文件、修改固定测试、预算耗尽、证据注入必须拒绝；补丁破坏旧行为必须被独立回归拦截。 |

## 实现时的文件职责

- `agent.py`：本角色处理逻辑，不创建独立的模型客户端或进程执行器。
- `contracts.py`：版本化且严格的输入、输出类型。
- `prompts/`：本角色提示词及版本说明，不存密钥。
- `tests/`：角色契约、权限、拒判、注入与预算测试；跨角色测试在根目录 `tests/agents/`。

当前已有contracts.py和tests；agent.py/prompts在P0-05b实现。角色间禁止直接导入对方实现，交接经编排器与显式契约。新增或调整角色需同步 [维护指南](../../../../docs/09-agent-modules.md)。
