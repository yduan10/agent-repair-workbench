# Single 角色：P0-06 对照组

任务 P0-06 / B3a。此目录提供单角色的模型输出契约和提示词，运行器另行接入。

- 输入：宿主审核的证据、授权片段、契约和可信工具反馈。
- 输出：T01–T07 请求，或 `handoff / needs_evidence` 结论。
- 权限：与三角色权限并集相同；路径、预算、工具执行、最终判定仍归宿主。
- 预算：同一任务共享两候选、12 模型请求、20 工具请求及配置的时间/token 限额；角色不自行设置额度。
- 触发：用户选择单角色对照模式；不动态注册角色。
- 停止：由宿主依据预算、取消、未知结果、证据不足或比较结果决定。
- 维护：角色契约/提示词和单测放本目录，共享协议放 `repair_contracts/`；不复制网关或运行器。

`handoff` 只请求宿主继续分派，不能代表验证通过；`needs_evidence` 由宿主收束到 `inconclusive`。
新候选只在隔离副本应用，不写回用户项目。此契约不包含接受操作或模型自报成功。
