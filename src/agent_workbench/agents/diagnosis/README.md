# 诊断 Agent

状态：P0-05b 已实现 `agent.py` 与版本化提示词，复用共享网关和宿主执行控制器；见 [交付验收](../../../../docs/25-p0-05b-delivery.md)。

| 项目 | 约束 |
|---|---|
| 输入 | 来源明确的调用证据摘要、契约报告、允许读取的代码快照。 |
| 输出 | 带证据引用的假设、待验证问题及有界复现建议；未经程序验证始终标 hypothesis / inconclusive。 |
| 权限 | 可读取证据并申请审核过的受控复现；不得写源码、修改固定验收、执行模型生成的命令或代替验证角色宣告修复成功。 |
| 验收 | 给定同一证据能输出符合契约的假设；引用缺失、提示注入、权限越界、上下文超限必须被拒绝或明确拒判。 |

## 实现时的文件职责

- `agent.py`：本角色处理逻辑，不创建独立的模型客户端或进程执行器。
- `contracts.py`：版本化且严格的输入、输出类型。
- `prompts/`：本角色提示词及版本说明，不存密钥。
- `tests/`：角色契约、权限、拒判、注入与预算测试；跨角色测试在根目录 `tests/agents/`。

当前已有 contracts.py、tests、agent.py 与 prompts/v1.txt（内容版本 v1.1，配置摘要绑定）。角色间禁止直接导入对方实现，交接经编排器与显式契约。新增或调整角色需同步 [维护指南](../../../../docs/09-agent-modules.md)。
