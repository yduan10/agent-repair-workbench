# UI-02：主题、页面动效与迭代历史

2026-10-13；Feature P1 产品体验增量。依据用户本轮指令实现；MCP 适配仍按 P0-02 推进。本记录不修改后端任务完成状态。

## 1. 设计计划与自审

采用 frontend-design skill 的两阶段过程。第一阶段确定：日间云蓝、夜间深海蓝两套主题；产品视觉中心保留可核对的调用证据。核心颜色为云蓝 `#EEF3FA`、纸面 `#FFFFFF`、墨色 `#16243D`、钴蓝 `#335CDE`、深海 `#101B30`、夜间文字 `#E9F0FC`。正文为系统中文无衬线，JSON 与代码为等宽字体。默认跟随系统，用户可选择浅色或深色。

布局延续首页左侧产品主张、右侧调用证据；工作区共享侧栏。新增独立迭代记录页，使用真实里程碑编号组织历史：最新在前，旧节点可展开。首页主标题采用逐行揭示，证据面板随后进入；交互反馈使用短距离图标位移和展开动画。

第二阶段自审：原方案不能仅替换背景色，否则深色模式的灰蓝文字、提示状态与输入框会失去对比度。因此本次将表面、文字、边界、错误/成功背景和按钮前景统一为语义 token；代码区始终保持深色。动效集中在一次首屏编排与用户交互，避免全页不断运动。历史用 DOC-01 / P0-01 / UI-01 / P0-02 / UI-02 标识，不创造对外发布版本。

## 2. 主题行为与数据边界

- 三种偏好：light / dark / system。全站包含手机端均有带名称的原生 select；键盘方向键、Home/End 可切换，Tab 焦点可见。
- `<head>` 内同步前置脚本在页面内容渲染前读取偏好，设置根元素主题，避免等待 React hydration 后才换色。SSR 根元素使用 suppressHydrationWarning 仅接受主题属性差异。
- system 监听 `prefers-color-scheme` change，实时响应操作系统变化；手动偏好不被系统变化覆盖。
- localStorage 仅保存 `awb-theme` 的枚举值。跨标签页通过 storage event 同步。阻止存储时仍能在当前文档切换。
- 调用证据、报告与输入草稿仍不存入 localStorage；不引入外部字体、遥测或模型请求。
- 不开启主题色过渡造成闪白；主题切换立即应用。reduced-motion 关闭所有动画/过渡及平滑滚动，同时移除证据窗口的装饰旋转。
