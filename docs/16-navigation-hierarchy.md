# UI-04：产品信息入口与工作导航分层

## 要求与设计

2026-10-13，用户指出“产品介绍”与“迭代记录”在侧栏看起来像功能模块，要求调整入口位置并应用 frontend-design。

- 侧栏只保留品牌、主题、工作区和七个产品模块；删除底部大段说明和两个独立分隔行。
- 产品信息放在主内容最底部：左侧产品名，右侧一组“产品介绍 / 迭代记录”文字链接。移动端自然换行，不隐藏入口。
- 延续配色：云蓝 #EEF3FA、白 #FFFFFF、墨蓝 #16243D、钴蓝 #335CDE、深海 #101B30、夜间正文 #E9F0FC。中文系统无衬线；页脚12px，弱于模块导航但保持可读对比度。
- 链接不做按钮边框、徽标或模块图标；44px点击高度、可见焦点，悬停颜色与短下划线响应用户操作，遵守减少动效偏好。

布局：

```text
侧栏：工作模块       主内容：当前任务
                    …
                    Agent Workbench       产品介绍  迭代记录
```

设计自审：不在侧栏底部继续堆两张较小卡片，彻底把产品说明入口迁到主内容页脚；不加装饰图案或无关动效。功能页共用页脚组件，避免位置和样式再次漂移。

## 实现边界与验收

任务总览、调用检查、其余模块共用页脚。检查页的两条页脚导航复用现有草稿离开确认；取消离开后内容保留。品牌入口继续返回产品首页。

本次不改变功能状态/API；保留迭代历史并新增UI-04记录。验收复用现有浅深色、桌面手机、axe测试；将旧侧栏历史测试改为实际页脚路径，并扩展现有草稿导航测试。独立代码评审后标完成。
