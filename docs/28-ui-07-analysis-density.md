# UI-07：诊断页面信息层级与导航语义

2026-10-14；状态 planned → ready → in_progress → in_review → done。用户授权本次 UI 调整与独立评审。P0-06 后端工作保留，本批只调整已有能力的展示与操作。

## 目标

侧栏回答“去哪里”，分析页先回答“结果如何、下一步看什么”。用户需要时可查看全部原始结构化事件，不把开发台账、预算预留和证据哈希铺满主屏。

## 范围与设计

- 沿用浅色云蓝 / 深色海军蓝主题：浅色 canvas #eef3fa、surface #fff、ink #16243d、muted #52627b、blue #335cde、line #dfe6f0；深色沿用现有变量，不新加装饰背景。
- 字体沿用系统中文字体；页面标题24px、结论18px、正文13–14px、辅助信息12px。左对齐，阅读行长受控；字小不作为主要压缩手段。
- 侧栏可用模块只显示名称；尚未交付模块的导航提示来自统一能力目录。具体网页/CLI边界在页面使用入口和折叠能力说明中解释，不能隐藏后冒充全功能已交付。
- 诊断布局：紧凑页头（用途、终端启动入口）→历史列表/结果工作区→辅助文档入口。

```text
诊断分析                         在终端启动  刷新
[最近分析 / 搜索] | [结论、来源、下载摘要]
[日期、结果]     | [角色判断与证据]
                 | [关联运行] [关键用量]
                 | > 执行过程（筛选、分页、有限高度）
                 | > 用量详情  > 技术信息与恢复
```

- 过程记录默认关闭，展开后提供关键/全部事件、角色筛选和分页；真实事件序号与数量保留，不重新编号或造阶段信息。
- 未知结果和未结算预留在摘要中仍可见；原始模型文本未持久化，界面只展示已存在的结构化结论。
- CLI启动、协作接口、开发进度不再占大块首屏，真实入口保留；不增加任何模型执行/补丁应用API，不生成伪任务。
- 动效只用于展开和按钮状态反馈，遵守 reduced-motion；保持键盘操作、手机布局和错误重试。

## 验收

1. 已可用模块无重复绿色状态；未交付模块仍能识别。页面可找到启动方式和真实限制。
2. 真实形状分析首屏有结论、异常/未知提示与关联运行；过程记录默认关闭。
3. 多事件筛选/分页无漏项、无重复，过滤后页数有效；切换任务清除旧详情，断网保留已读取数据且标明过时。
4. 搜索历史不写数据库，空结果有清除入口；下载摘要仍完整。
5. 浅/深色、1440/1280/390布局、键盘和axe；真实本地记录浏览核对，禁止把测试数据写入主库。
6. 独立UI/代码评审、修复后复审，构建/类型与定向浏览器测试通过；同步台账、能力目录与开发历史。
