# UI-05：功能引导、文档入口与公开源码

日期：2026-10-13。状态：in_review。

## 需求及交付范围

用户要求修复深色空状态光晕、直接说明 Agent 测试、将迭代页作为开发记录、增加功能引导和文档 / GitHub 入口，并明确授权首次提交、推送至公开仓库。

- 产品展示名：Agent 修复台；仓库地址名：`agent-repair-workbench`。Python 包、CLI 和本机工程目录保持兼容。
- 首页直接说明目标用户、输入、输出及当前能力；三条操作入口进入检查、真实只读记录、接口目录。
- `/docs` 提供本地上手、可执行测试命令、当前测试层级和完整工程文档链接。
- GitHub 源码卡片在首页，文档 / 源码链接在工作区页脚；不混入工作模块。内部离开检查页继续保护草稿，外部源码新标签页打开。
- 开发记录保留全部历史，任务编号与发布版本分开；内容使用具体改动和验证结果。
- 移除 `.empty-result` 固定浅色径向渐变，图标叠层与边缘跟随主题。

## 设计决策

使用 frontend-design skill；延续本产品已有主题，避免为本次入口整理另造风格。
配色：云蓝背景 #eef3fa、白色表面 #ffffff、墨蓝正文 #16243d、石板蓝辅助 #52627b、交互蓝 #335cde；深色对应已有语义变量。中文沿用 PingFang SC / 系统无衬线，代码独立等宽。首页先说明用途再给入口；文档按快速上手、测试、工程参考排列。保留标题单次入场，箭头只响应悬停，遵循 reduced-motion；取消不承载运行含义的光晕。

## 测试与独立评审

- 验证首页入口可达、文档命令路径存在、源码链接目标固定、开发记录历史保留。
- 检查页真实 API 回归与文档/开发记录跳转的未保存草稿保护。
- 浅 / 深色，桌面 / 手机：空态可读、整页无横向溢出、键盘焦点、axe WCAG A/AA。
- TypeScript 与生产构建；角色/权限测试命令实际运行。
- 独立 UI 代码评审与发布候选集凭据/个人数据审计。

## 公开源码决策

依据用户本次明确授权创建公开仓库并推送开发快照，覆盖 AGENTS 的默认不推送规则。本次不是 P0/P1 全量验收完成或稳定产品发布；01 / 04 中的正式发布门禁继续有效。

公开范围仅 Git 纳入的源码、合成样例、测试、锁文件、规格和脱敏评审记录；不公开 `.env`、运行产物、模型配置、个人原始 trace、数据库和依赖缓存。历史本机路径作占位符处理，旧快照哈希不伪造更新。尚未选择项目开源许可证，在 README 明确说明。公开源码不等于产品公网部署。

目标仓库：https://github.com/yduan10/agent-repair-workbench 。创建 / 推送及远端 CI 结果在实际完成后记录。
