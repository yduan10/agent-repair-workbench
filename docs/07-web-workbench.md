# UI-01：产品入口与完整功能界面

版本 0.2 / 2026-10-13 / Feature P0。用户明确要求：前台产品设计先完成，后台能力按迭代解锁。界面完成度与功能可用性分别验收。

## 1. 产品目标与设计决策

面向 Agent / MCP 工具开发者，围绕“调用证据 → 诊断依据 → 候选修复 → 独立回归 → 项目经验”组织页面。首页需要解释适用用户、解决的问题、操作入口和可信依据；工作区承接具体操作。工程代号 Agent Workbench，最终品牌名尚未确定。

使用已获授权的第三方 `frontend-design` skill 做视觉设计，`web-design-guidelines` 做界面检查；专职 reviewer 独立评审代码。未引入其他项目的设计、命名或记忆。

### 视觉规范

- 纸白画布 #F7F9FC、白色表面、深墨蓝 #16243D、辅助文字 #52627B、钴蓝 #335CDE。状态有文字，不能只靠颜色识别。
- 系统中文无衬线与代码等宽字体；主页大标题建立层级，工作区优先可读性。无远端字体、图片或分析脚本。
- 首页使用真实业务结构的代码与证据卡片作为主视觉，明确标注合成案例。留白、分栏、边界和层次为阅读路径服务。
- 动效为 180–240ms 的状态切换、按钮反馈和结果进入；以 transform/opacity 实现，尊重 reduced-motion。等待动画只代表真实请求等待。
- 工作区共用导航、标题栏、内容区和状态语言。桌面双栏，手机堆叠；手机导航内部横向滚动，页面本身不得横向撑宽。
- 品牌标识暂用括号与验证点组合的矢量图形。此项为工程代号的临时标识，最终品牌设计另行验收。

## 3. 真实检查流程与数据保真

选择合成样本或导入本地 UTF-8 JSON → 编辑 → 本机 Python 检查 → 查看结论、覆盖范围和问题路径 → 显式下载报告。

- 初始不展示伪造检查结果，页面结论只来自真实 API 响应。
- JSON 原文直传，不通过 JSON.parse/stringify 重写用户输入；数字字面量、重复键和 UTF-8 BOM 都保留给检查器处理。内置手写样本不作为真实历史故障。
- 编辑立即清空旧报告；请求期间锁定编辑、重复提交和样本切换。
- 替换未保存内容、侧栏跳转有确认；刷新/关闭使用 beforeunload。浏览器站内后退通过标签页 JS 内存保留草稿，前进或再进入可恢复；不使用 localStorage/sessionStorage，刷新后清除。
- 文件导入失败保留当前证据与对应报告，并明确提示未替换。导入成功即使内容非法，也交给检查器判定，不静默修正。
- 服务异常与契约失败分开展示；不具备输出契约标记未检查，不把未知判成通过。

## 4. 本地 API 契约

Next.js App Router + TypeScript + Tailwind/CSS tokens；FastAPI 薄适配层复用 P0-01 限时子进程检查器。网页 `127.0.0.1:3010`，API `127.0.0.1:8030`，Next 同源转发 `/api/check` 和 `/api/health`。

- `GET /api/health` → `{status: "ok", checker_version: ...}`，仅表示本地检查 API 可用。
- `POST /api/check`：application/json 原始字节，≤1 MiB；接收最多 5 秒，检查最多 5 秒。
- 单执行槽：读体/检查期间第二请求立即 429，health 不受检查占用影响。请求取消后独立 worker 仍持槽，到有界检查结束才释放；服务正常关闭等待在途 worker。
- 200 为 Report v1，status 为 passed / failed / inconclusive，HTTP 200 不代表契约通过。
- 400/403/408/413/415/429/503 使用固定 JSON `error`；Host、Origin 和 Sec-Fetch-Site 边界均测试，不输出原始值或异常文本。
- 仅监听回环地址，不开放 CORS；no-store、nosniff、frame DENY。无身份系统，不可将当前配置作为公网服务部署。
- API 不接收命令/路径、不持久保存原始输入、不打印请求体。报告由用户主动下载。

## 5. 验收矩阵

| 层 | 检查内容 | 通过条件 |
|---|---|---|
| API 真集成 | 成功、失败、缺结果、数值精度、重复键 | 同输入与现有检查器报告一致 |
| API 生命周期 | 忙碌、取消、worker异常、关闭、重复取消 | 不超并发槽；结束后槽可重用 |
| API 请求边界 | 大小、媒体类型、Host、Origin、跨站 | 状态及固定错误符合契约，无值泄漏 |
| 浏览器真流程 | 首页→检查→展开证据→下载 | 使用真实 HTTP + Python 检查，非 mock 唯一验收 |
| 浏览器保真 | 大数字、重复键、UTF-8 BOM | 拒判与 CLI 一致，发出的 BOM 字节不丢失 |
| 浏览器状态 | 编辑失效、断网恢复、草稿导航、导入失败 | 无过期结果冒充新结果，无静默证据替换 |
| 完整 UI | 六个预览页导航、筛选、详情、配置 | 无死链接；明确合成来源与后续解锁；非法模块404 |
| 可访问性 | 桌面/手机8页axe WCAG2A/AA、标签、焦点 | 自动检查无违规；人工核对主要键盘操作 |
| 视觉 | 1440px / 390px 截图 | 页面不横向溢出，实际看图核对层级及可读性 |
| 工程 | Python、Ruff、mypy、TS、production build | 全部通过，独立 review 的 P0/P1 闭合 |
