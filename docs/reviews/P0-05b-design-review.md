### 授权后的模型上界增量

- 第 26 行的固定 profile 可按用户新授权采用条件性 provider 上界信任。2026-10-14 独立打开官方模型页，确认当前 `deepseek-flash` 对应 DeepSeek-V4.1-Flash、上下文为 1M、最大输出为 384K；该页不证明用户网关的别名映射或强制限额。[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)
- 输入预留 1,048,576，加按角色设置的显式输出上限（诊断/验证 4,096、修复建议 8,192，受 Task Budget.output_tokens 裁剪），能够覆盖本次采用的官方 1M 口径。任务预算提高至 2,000,000 与该预留相容；合法 usage 结算释放差额，不把预留宣称为已消费 token。
- 实现门禁：profile 精确绑定获授权的网关配置、模型名和计数方法版本；未知配置拒发。请求输出限额必须生效于所采用的 completion/推理计数语义；usage 应校验 prompt+completion=total，缺失、矛盾、超限保持预留并终止后续调用。后端 token schema、前端 DTO 及边界测试同步 2M，旧 1M 配置仍合法但可能无法容纳一次真实预留；独立核对 contracts.py 已将 TokenCount 分离为 2M，revision Count 保留 1M。
- 第 81 行明确 length 截断时先结算合法 usage，再以 MODEL_OUTPUT_TRUNCATED 停止，不采纳半份建议、不当作普通结构纠错重投；usage 本身异常仍执行保留预留规则。第 26 行角色上限已与第 9 节一致。主协调者确认 CLI 的 TaskBudget.output_tokens 默认 8,192；该默认值及每角色裁剪、截断分支留 B3 代码与测试核验，此次不冒充已测实现。

## 6. 架构防腐与长效治理建议

1. 将单次发送许可与存储幂等分开验证；即使不启用 checkpoint，也保留节点重入反例。
2. LangGraph 的 private state 并不自动防止 stream 泄露；CLI/API 仅输出安全摘要/事件，错误、日志和 stream 都用哨兵检查。该边界由实现测试证明。[官方 Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)
3. DeepSeek 官方字符换算明确为近似值，不能代替本项目网关部署的硬上限证据；非本次授权固定 profile 或缺少相应依据时继续拒绝真实调用，不将 A14 标为完成。[官方 token 说明](https://api-docs.deepseek.com/quick_start/token_usage/)
