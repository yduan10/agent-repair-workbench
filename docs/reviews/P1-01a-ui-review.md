## 3. 详细审计明细

- `components/reproduction-panel.tsx` 使用同步 ref 防双击，POST 前保存规范 request_id/scenario；不确定结果保留 ID，重载与手动查询仅 GET。页面离开中止请求，不发送自动 cancel。
- `components/run-history.tsx` 用选择版本防止迟到启动应答覆盖新的历史选择；列表与详情请求可中止；运行状态串行定时读取，离页清理计时器。
- `components/run-detail.tsx` 仅 catalog 的 active_run_id 匹配、状态仍活动时允许停止；同步 guard 防重复；应答只说明 cancel_requested，实际终态继续来自详情。切换记录中止旧停止请求的 UI 更新。
- `lib/reproductions.ts` 严格验证四场景、目录唯一性、返回 ID/场景关联与取消关联；错误正文不回显；下载配置和复制命令仅使用枚举生成固定字符串，未引入 shell 执行。
- `components/run-report.tsx`、`lib/runs.ts` 先校验完整 schema、原字节 SHA 和 record/attempt 双 ID，随后才渲染摘要；下载重新验证并保留原字节；切换、刷新或离页使旧下载失效。
- `next.config.ts` 仅增加 catalog、创建和规范 UUID cancel 三条准确转发，不使用泛路由扩大后端范围。
- 用户文案继续声明合成来源、固定场景、已有 CLI 历史只称同场景新建；自定义工具、模型修复和审批未被描述为完成。能力说明保留“正在验收”，不由本报告提前标父任务完成。
- 样式复用主题变量；命令局部横向滚动，手机单列，键盘焦点及 reduced-motion 规则存在。独立 390px 深色截图显示控件、报告、技术详情和页脚未裁切，桌面/手机两主题 axe 与溢出检查全部通过。

1. 将不确定请求保留及迟到下载取消作为持续回归，避免未来优化轮询时引入重复执行或过时下载。
