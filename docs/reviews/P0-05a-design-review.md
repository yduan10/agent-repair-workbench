## 2. 生产事故风险推演

下列为初审的可实现歧义和反例，均已修订关闭；不是声称当前不存在的 Agent 代码已经发生故障。

- **D01 授权目标不完整**：若实现仅比较合法 profile/UUID 与角色权限，而未绑定全部请求参数，改变版本、源码行范围或证据哈希仍可能获准。若修复结论只检查引用而不检查 edits 的 path/basehash，则能接受任务范围外提案。爆炸半径为单任务授权边界；本批不写文件，未来不得将未授权提案传入写入器。
- **D02 摘要版本与余额不明确**：同一 diagnosing 阶段可以发生多次模型/工具步骤，若持久摘要只能使用阶段 revision，第二个同阶段更新会冲突或覆盖；两个 task_id 未要求相等则可能关联错误任务。若 usage 未定义已知消费与保留量之和，记录会低报预算。爆炸半径为单任务状态/成本可信度。
